# Security policy

## Supported version

Security fixes are made on the current `main` branch.

## Report a vulnerability

Please do not open a public issue for a vulnerability involving uploaded
material, authentication, storage access, AI prompts, or Cloudflare/Supabase
configuration. Email the maintainer listed on the GitHub repository profile
with:

- a concise description of the issue;
- steps to reproduce it safely;
- the potential impact; and
- any suggested mitigation.

Do not include real student documents, credentials, access tokens, or personal
data. We will acknowledge reports and aim to provide a status update within
seven days.

## Scope

Particularly useful reports include unsafe PDF or archive parsing, cross-user
material access, prompt-injection paths, rate-limit bypasses, and accidental
exposure of configuration secrets.
