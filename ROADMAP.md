# Kelus roadmap

Kelus is an open-source study tool for one narrow promise: a student should be able to trace every correction back to their own course material.

## Working now

- Local-first course materials: PDFs, slide decks, notes, Notion exports, and pasted text.
- Source-linked topics and recall checks.
- Answer feedback that shows the supporting line and what returns in the next warm-up.
- A study plan that changes from what a student actually recalled.

## Improving next

1. Make imported PDFs, scans, and slide decks more reliable across real course formats.
2. Let students correct a poor topic or source match without losing their work.
3. Make past-paper questions easy to connect to supporting course material.
4. Improve accessibility, keyboard use, and small-screen study sessions.

## Good ways to help

- Add an openly licensed or synthetic fixture that exposes an import edge case.
- Improve a screen reader, keyboard, contrast, or reduced-motion experience.
- Improve documentation, setup, or reproducible local testing.
- Report an unclear or unsupported question without including private course material.

## Boundaries

Kelus will not claim that a student is exam-ready from a guessed score. It will not treat uploaded text as instructions, and it will not use private student material as a public fixture. See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md) before opening an issue or pull request.
